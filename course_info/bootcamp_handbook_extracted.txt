ข้อมูลการเข้าอบรม On-site
ช่วงการอบรม ต้องลงทะเบียนก่อนเข้าอบรมหรือไม่?
— ต้อง Check-in ตามจุดลงทะเบียนที่ Staff กำหนด โดยแบ่งเป็น 2 ช่วงเวลาต่อวัน ได้แก่
ช่วงเช้าและช่วงบ่าย

เช็คอินไม่ครบ 80% มีสิทธิรับใบประกาศนียบัตรหรือไม่?
— กรุณาวางแผนเข้าร่วมให้ครบตามระยะเวลาขันตําทีโครงการกําหนดไว้

สถานที่อบรมมี Wi-Fi ให้หรือไม่?
— โครงการมีบริการ Wi-Fi ให้กับผู้เข้าร่วมการอบรม โดยผู้จัดจะแจ้งรายละเอียด
Network/Wi-Fi และวิธีเชือมต่อก่อนเริมกิจกรรม

มีอาหารกลางวัน/อาหารว่างสนับสนุนหรือไม่?
— โครงการจัดเตรียมอาหารกลางวันและอาหารว่างช่วงเช้า ช่วงบ่ายให้ตลอดการอบรม

หากไม่สามารถมาอบรมได้ 1 วันต้องทําอย่างไร?
— แจ้ง Staff/ผู้ประสานงานล่วงหน้า และตรวจสอบว่ามีเงื่อนไขการชดเชยหรือกิจกรรมทดแทน
หรือไม่

ต้องเข้าเรียนกีเปอร์เซ็นต์จึงจะผ่าน?
— ตามเงื่อนไขของโครงการฯ ผู้เข้าร่วมต้องมีการเข้าร่วมอบรมอย่างน้อย 80% ขึ้นไป
ขอความกรุณาผู้เข้าร่วมวางแผนเข้าร่วมให้ครบตามระยะเวลาขันตําทีโครงการกําหนดไว้

มีทีจอดรถทีเอ็มเพรสและ STeP หรือไม่?
— มีทั้งสองจุดแต่มีจำกัด เนื่องจากทางสถานที่ต้องให้บริการลูกค้าและผู้ใช้บริการอื่น ๆ ด้วย
กรุณาวางแผนล่วงหน้า

เกี่ยวกับ Capstone Project
Capstone Project คืออะไร?
— Capstone Project คือโครงงานที่ผู้เข้าอบรมจะนำความรู้จากตลอดหลักสูตร AIoT มา
ประยุกต์ใช้ในการแก้ปัญหาหรือสร้างต้นแบบระบบ AIoT ที่สามารถเชื่อมโยง IoT + Data + AI +
Application/Business Use Case เข้าด้วยกัน

Capstone Project ทำเปนรายบุคคลหรือเปนทีม?
— ดำเนินการทําโครงงานเปนกลุ่ม โดยจํานวนสมาชิกต่อทีมให้เปนไปตามทีผู้จัดอบรมกําหนด

Capstone Project มีการให้คะแนนหรือไม่?
— มีการให้คะแนน เปนการประเมินจากอาจารย์วิทยากร โดยโครงการฯ จะมีการแจ้งเงือนไข
การและเกณฑ์การให้คะแนนอีกครังในช่วงของการอบรม On-site

Capstone Project มีผลต่อการผ่านหลักสูตรหรือไม่?
— Capstone Project หรือโครงการเป็นเงื่อนไขหนึ่งของเกณฑ์การผ่านการฝึกอบรมและได้รับ
ประกาศนียบัตร โดยคิดเปน 50% ของหลักสูตร
