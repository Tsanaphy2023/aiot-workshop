## 🎯 เกณฑ์การประเมินและการรับประกาศนียบัตร (Certificate)
1. **การเช็กอิน:** สแกน QR Code วันละ 2 ครั้ง (เช้า/บ่าย) ไม่น้อยกว่า 80% (อย่างน้อย 8 จาก 10 ครั้ง)
2. **แบบทดสอบ (Pre-test / Post-test):** ทำแบบทดสอบในระบบครบทุกหัวข้อ โดยแบบทดสอบหลังเรียน (Post-test รวม 8 ชุด) ต้องได้คะแนน **ไม่น้อยกว่า 60%** (มีสิทธิ์สอบแก้ตัว Attempt ครั้งที่ 2 ได้)
3. **Capstone Project (50% ของหลักสูตร):** นำเสนอผลงานพัฒนาต้นแบบระบบ Smart Farm ในรูปแบบ Pitching วันที่ 29 กันยายน 2569 เวลา 15:00 - 18:00 น.
