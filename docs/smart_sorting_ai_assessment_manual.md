# 📘 คู่มือคลังแบบทดสอบประเมินสมรรถนะการเรียนรู้และเฉลยเชิงวิเคราะห์
## ระบบคอมพิวเตอร์วิทัศน์ การตรวจจับวัตถุ และระบบคัดแยกอัจฉริยะบนสายพานลำเลียง (Computer Vision & Smart Sorting AIoT)
**หลักสูตรวิทยาการข้อมูลและปัญญาประดิษฐ์ฝังตัวเพื่อการเกษตรแม่นยำ**  
**มหาวิทยาลัยเชียงใหม่ ร่วมกับ มหาวิทยาลัยราชภัฏรำไพพรรณี**

### สารบัญแบบทดสอบจำแนกตามสมรรถนะ (Competency Matrix)
1. **หมวดที่ 1:** มโนทัศน์พื้นฐานด้านภาพดิจิทัลและคอมพิวเตอร์วิทัศน์ (ข้อ 13)
2. **หมวดที่ 2:** การจัดการชุดข้อมูลภาพและแพลตฟอร์ม Roboflow (ข้อ 3, 4, 5, 6, 7)
3. **หมวดที่ 3:** สถาปัตยกรรมโมเดล YOLO และการประเมินประสิทธิภาพ (ข้อ 1, 2, 8, 9, 10)
4. **หมวดที่ 4:** วิศวกรรมระบบฮาร์ดแวร์ Edge AI และบอร์ดเดี่ยว Raspberry Pi (ข้อ 11, 12, 14, 16)
5. **หมวดที่ 5:** การคำนวณทางฟิสิกส์ การควบคุม และการบริหารจัดการโครงการ SME (ข้อ 15, 17, 18, 19)

### 1. หมวดมโนทัศน์พื้นฐานด้านภาพดิจิทัลและคอมพิวเตอร์วิทัศน์

#### ข้อที่ 1 (ข้อ 13 ในระบบ)
**คำถาม:** หัวใจสำคัญเบื้องหลังภาพถ่ายที่คอมพิวเตอร์มองเห็น คือโครงสร้างข้อมูลในข้อใด?  
- [ ] ก. รหัสผ่านลับของผู้ใช้งาน  
- [ ] ข. เสียงดนตรีดิจิทัล  
- [ ] ค. ไฟล์เอกสาร Word  
- [x] **ง. ตารางตัวเลขพิกเซล (Grid of Numbers)**  

> **เฉลยเชิงวิเคราะห์:** ในทางวิทยาการคอมพิวเตอร์และปัญญาประดิษฐ์ คอมพิวเตอร์ไม่ได้รับรู้ภาพเป็นภาพศิลปะหรือรูปร่างเหมือนสายตามนุษย์ แต่มองเห็นภาพเป็น **เมทริกซ์หรือเทนเซอร์ของตัวเลข 2 หรือ 3 มิติ (2D/3D Tensor)** ที่แต่ละพิกเซลเก็บค่าความสว่างตั้งแต่ 0 (มืดสนิท) ถึง 255 (สว่างสุด) โดยภาพสีแบบ RGB จะประกอบด้วยตารางตัวเลข 3 แชนเนลซ้อนทับกัน ตัวเลขเหล่านี้คือข้อมูลตั้งต้นที่อัลกอริทึม Deep Learning นำไปคำนวณทางคณิตศาสตร์

### 2. หมวดการจัดการชุดข้อมูลภาพและแพลตฟอร์ม Roboflow

#### ข้อที่ 2 (ข้อ 6 ในระบบ)
**คำถาม:** เว็บไซต์หรือแพลตฟอร์มใดที่ใช้ในการสร้างโปรเจกต์จัดการข้อมูลภาพ และทำ Data Augmentation ในบทเรียนนี้?  
- [x] **ก. Roboflow**  
- [ ] ข. Canva  
- [ ] ค. Google Drive  
- [ ] ง. Microsoft Word  

> **เฉลยเชิงวิเคราะห์:** **Roboflow** คือแพลตฟอร์มคลาวด์มาตรฐานสากลสำหรับนักพัฒนา Computer Vision รองรับการอัปโหลดไฟล์ภาพ การตีกรอบระบุพิกัดวัตถุ (Annotation) การแปลงฟอร์แมตข้อมูล (YOLO, COCO, VOC) ตลอดจนการทำ Preprocessing และ Data Augmentation อย่างเป็นระบบ

#### ข้อที่ 3 (ข้อ 3 ในระบบ)
**คำถาม:** ชื่อ Class สองกลุ่มหลักที่ใช้ในการคัดแยกผลผลิตปกติและผลผลิตเสียหายตามบทเรียนคือข้อใด?  
- [ ] ก. start / stop  
- [x] **ข. healthy / rotten**  
- [ ] ค. true / false  
- [ ] ง. open / close  

> **เฉลยเชิงวิเคราะห์:** ในการฝึกสอนโมเดลคัดแยกเกรดและคุณภาพผลผลิตทางการเกษตร คลาสมาตรฐานที่นิยมใช้ในระดับสากล ได้แก่ **`healthy`** สำหรับผลผลิตสมบูรณ์ ผิวดี ได้มาตรฐาน และ **`rotten`** สำหรับผลผลิตที่มีตำหนิ รอยแตก หรือเน่าเสีย

#### ข้อที่ 4 (ข้อ 5 ในระบบ)
**คำถาม:** ข้อใดคือลักษณะของการวาดกรอบ Bounding Box ที่ ผิดพลาด และส่งผลให้ AI เรียนรู้ผิดเพี้ยนไปจากความเป็นจริง?  
- [ ] ก. ตั้งชื่อ Class ให้ตรงกันทุกรูป  
- [ ] ข. แยกวาดกรอบแต่ละลูกกรณีที่ผลไม้วางอยู่ติดกัน  
- [x] **ค. วาดกรอบหลวมเกินไปจนติดฉากหลังสายพาน ทำให้ AI คิดว่าสายพานคือส่วนหนึ่งของแผล**  
- [ ] ง. วาดกรอบสี่เหลี่ยมให้ชิดขอบวัตถุพอดี  

> **เฉลยเชิงวิเคราะห์:** การตีกรอบหลวมเกินไปจะทำให้พิกเซลของฉากหลัง (เช่น สีและลวดลายของสายพานลำเลียง) ถูกรวมเข้าไปในคลาสรอยโรค โมเดลจะจดจำฟีเจอร์ของสายพานเป็นส่วนหนึ่งของแผลเน่า ก่อให้เกิดปัญหาโมเดลทำนายผิดพลาด (False Positive) เมื่อนำไปใช้งานจริง

#### ข้อที่ 5 (ข้อ 7 ในระบบ)
**คำถาม:** หากต้องการเพิ่มจำนวนภาพถ่ายโดยอัตโนมัติ เพื่อจำลองสภาพแสงและมุมมองที่หลากหลายบนสายพานโดยไม่ต้องออกไปถ่ายรูปใหม่ เราควรใช้ฟังก์ชันใด?  
- [ ] ก. Image Compression  
- [ ] ข. File Deletion  
- [ ] ค. Background Erase  
- [x] **ง. Data Augmentation**  

> **เฉลยเชิงวิเคราะห์:** **Data Augmentation** คือกระบวนการเพิ่มความหลากหลายและปริมาณของชุดข้อมูลฝึกสอน โดยการจำลองการเปลี่ยนแปลงทางเรขาคณิตและสี เช่น การหมุนภาพ การกลับด้านซ้ายขวา การปรับค่าความสว่าง และการเพิ่มสัญญาณรบกวน ช่วยให้โมเดลมีความทนทานต่อสภาพแวดล้อมจริงในโรงงาน

#### ข้อที่ 6 (ข้อ 4 ในระบบ)
**คำถาม:** เมื่อเราวาดกรอบภาพครบถ้วน 100% แล้ว สิ่งที่ระบบใน Roboflow จะปลดล็อกให้เราทำเป็นขั้นตอนถัดไปเพื่อเตรียมนำชุดข้อมูลไปใช้งานคือข้อใด?  
- [ ] ก. ปุ่มแชร์หน้าจอไปยังโซเชียลมีเดีย  
- [ ] ข. ปุ่มลบโปรเจกต์ทิ้งทั้งหมด  
- [ ] ค. ปุ่มเปลี่ยนรหัสผ่านผู้ใช้งาน  
- [x] **ง. ปุ่ม Generate Dataset**  

> **เฉลยเชิงวิเคราะห์:** เมื่อติดป้ายกำกับวัตถุครบทุกภาพ ระบบจะปลดล็อกขั้นตอน **Generate** เพื่อให้ผู้พัฒนาคลิกปุ่ม **Generate Dataset** สำหรับประมวลผล Preprocessing/Augmentation และสร้างเวอร์ชันชุดข้อมูลที่พร้อมดาวน์โหลดหรือดึงผ่าน REST API เข้าสู่ Google Colab

### 3. หมวดสถาปัตยกรรมโมเดล YOLO และการประเมินประสิทธิภาพ

#### ข้อที่ 7 (ข้อ 2 ในระบบ)
**คำถาม:** เป้าหมายหลักของการใช้เทคโนโลยี Object Detection บนสายพานลำเลียงในโรงงานคือข้อใด?  
- [ ] ก. เพื่อบันทึกภาพเก็บไว้ทำรายงานประจำปี  
- [ ] ข. เพื่อปรับเปลี่ยนรูปร่างของผลไม้ให้ได้มาตรฐาน  
- [ ] ค. เพื่อเพิ่มความเร็วในการเคลื่อนที่ของสายพานให้เร็วขึ้น  
- [x] **ง. เพื่อตรวจจับและตีกรอบระบุตำแหน่งของผลผลิตหลายลูกพร้อมกัน เพื่อคัดแยกของเสียออกจากสายพาน**  

> **เฉลยเชิงวิเคราะห์:** เทคโนโลยี Object Detection แตกต่างจาก Image Classification ตรงที่สามารถตรวจจับวัตถุได้หลายชิ้นพร้อมกันในหนึ่งเฟรม (Multi-object Detection) และส่งออกพิกัดจุดกึ่งกลาง $(x, y)$ ของผลผลิตทุกลูกบนสายพาน ทำให้ระบบนำพิกัดตำแหน่งไปสั่งการแขนกลหรือหัวพ่นลมได้อย่างตรงจุด

#### ข้อที่ 8 (ข้อ 10 ในระบบ)
**คำถาม:** โมเดล YOLOv8 ขนาดใด ที่ถูกออกแบบมาให้มีขนาดเล็ก น้ำหนักเบา และมีความเร็วสูงสุด เหมาะสำหรับนำไปใช้กับกล้องติดสายพานความเร็วสูงหรือบอร์ดสมองกลขนาดเล็ก?  
- [ ] ก. YOLOv8x (Extra Large)  
- [ ] ข. YOLOv8m (Medium)  
- [x] **ค. YOLOv8n (Nano)**  
- [ ] ง. YOLOv8s (Small)  

> **เฉลยเชิงวิเคราะห์:** ตระกูล YOLO โมเดลรุ่น **Nano (n)** มีจำนวนพารามิเตอร์ต่ำที่สุด (~3.2 ล้านพารามิเตอร์) และขนาดไฟล์เพียง ~6 MB จึงให้ค่าเวลาแฝงในการอนุมานผล (Inference Latency) สั้นที่สุด เหมาะสมที่สุดสำหรับการติดตั้งบนบอร์ดสมองกลฝังตัวที่มีทรัพยากรจำกัด

#### ข้อที่ 9 (ข้อ 9 ในระบบ)
**คำถาม:** ไฟล์น้ำหนักที่ดีที่สุดที่ระบบการฝึกอบรม (Training) คัดเลือกและจัดเก็บไว้ให้โดยอัตโนมัติ เพื่อให้นำไปใช้ในการทดสอบจริง มีชื่อเรียกว่าอะไร?  
- [ ] ก. config.json  
- [ ] ข. yolov8n.pt  
- [x] **ค. best.pt**  
- [ ] ง. data.yaml  

> **เฉลยเชิงวิเคราะห์:** ในระหว่างการฝึกสอน YOLO เฟรมเวิร์กจะทำการทดสอบบนชุด Validation ในทุก ๆ รอบ (Epoch) แล้วทำการบันทึกไฟล์น้ำหนักที่ให้ค่าความแม่นยำสูงสุดไว้ในชื่อ **`best.pt`** ส่วน `last.pt` คือไฟล์ของรอบสุดท้าย และ `data.yaml` คือไฟล์การตั้งค่าโครงสร้างข้อมูล

#### ข้อที่ 10 (ข้อ 1 ในระบบ)
**คำถาม:** ข้อใดคือความหมายและประโยชน์ของค่า Precision (ความแม่นยำ) ในการประเมินผล AI?  
- [ ] ก. ความเร็วในการเปิดดูภาพซ้ำๆ ของ AI  
- [ ] ข. ขนาดความจุของไฟล์โมเดลหลังการเทรน  
- [ ] ค. มีผลเน่าทั้งหมด 100 ลูก AI ตรวจเจอครบกี่ลูก  
- [x] **ง. ทายว่าเน่า แล้วเน่าจริงกี่เปอร์เซ็นต์ (ช่วยป้องกันการตัดผลผลิตดีทิ้งโดยเปล่าประโยชน์)**  

> **เฉลยเชิงวิเคราะห์:** ค่า Precision คำนวณจากสูตร $TP / (TP + FP)$ บ่งชี้ว่าจากสิ่งที่ AI ทายว่าเป็นผลเน่าทั้งหมดนั้น มันเน่าจริงกี่เปอร์เซ็นต์ ประโยชน์คือช่วยควบคุมความผิดพลาดแบบ False Positive ป้องกันไม่ให้ระบบตีตราผลผลิตเกรดดีว่าเป็นผลเสียจนถูกคัดทิ้งโดยสูญเปล่า

#### ข้อที่ 11 (ข้อ 8 ในระบบ)
**คำถาม:** ข้อใดคือความหมายของค่า Recall (การเก็บตกครบ) ในการประเมินผล AI?  
- [ ] ก. การย้อนกลับไปแก้ไขภาพที่วาดกรอบผิดพลาด  
- [ ] ข. ความสามารถในการจดจำชื่อผู้ใช้งานระบบ  
- [ ] ค. การคำนวณต้นทุนค่าใช้จ่ายในการสร้างระบบ AI  
- [x] **ง. การตรวจสอบว่าผลเน่าทั้งหมดที่มี AI สามารถตรวจจับเจอครบถ้วนหรือไม่ เพื่อป้องกันผลเน่าหลุดรอดไปถึงมือลูกค้า**  

> **เฉลยเชิงวิเคราะห์:** ค่า Recall คำนวณจากสูตร $TP / (TP + FN)$ บ่งชี้ความครอบคลุมในการกวาดตรวจจับวัตถุเป้าหมายจริงทั้งหมด มีความสำคัญอย่างยิ่งในงานควบคุมคุณภาพสินค้า เพื่อรับประกันว่าไม่มีผลผลิตเน่าเสียหลุดรอดสายตา AI ออกไปสู่ตลาด

### 4. หมวดวิศวกรรมระบบฮาร์ดแวร์ Edge AI และบอร์ดเดี่ยว Raspberry Pi

#### ข้อที่ 12 (ข้อ 12 ในระบบ)
**คำถาม:** อุปกรณ์ชิ้นใดทำหน้าที่เปรียบเสมือน "สมองกลขนาดจิ๋ว" ที่ติดตั้งหน้างานเพื่อรันระบบ AI ประมวลผลแบบ Edge Computing โดยไม่ต้องพึ่งพาอินเทอร์เน็ต?  
- [x] **ก. คอมพิวเตอร์บอร์ดเดี่ยว (เช่น Raspberry Pi)**

- [ ] ค. เครื่องปริ้นเตอร์เอกสาร  
- [ ] ง. โทรศัพท์มือถือรุ่นเก่า  

> **เฉลยเชิงวิเคราะห์:** คอมพิวเตอร์บอร์ดเดี่ยว (Single-Board Computer: SBC) เช่น Raspberry Pi รวบรวมหน่วยประมวลผลกลาง แรม และพอร์ตเชื่อมต่อไว้บนบอร์ดเดียว สามารถติดตั้งระบบปฏิบัติการ Linux และรันโมเดล AI ในรูปแบบ Edge Computing ได้โดยอิสระโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

#### ข้อที่ 13 (ข้อ 11 ในระบบ)
**คำถาม:** ข้อใดอธิบายหน้าที่หลักของบอร์ด Raspberry Pi เมื่อนำมาติดตั้งใช้งานจริงบนสายพานลำเลียง?  
- [x] **ก. ทำหน้าที่รันโมเดลเพื่อทายภาพสด (Inference) ควบคุมรับส่งสัญญาณผ่าน GPIO และสั่งการกลไกคัดแยกที่หน้างาน**  
- [ ] ข. ทำหน้าที่พิมพ์ฉลากสินค้าและบาร์โค้ด  
- [ ] ค. ทำหน้าที่เป็นเครื่องแม่ข่ายสำหรับอัปโหลดคลิปวิดีโอขึ้น YouTube  
- [ ] ง. ทำหน้าที่เป็นแหล่งเก็บเงินสดของโรงงาน  

> **เฉลยเชิงวิเคราะห์:** Raspberry Pi หน้างานทำหน้าที่ครบวงจร ตั้งแต่การดึงสตรีมภาพสดจากกล้องมารันโมเดล YOLO ประมวลผลตำแหน่งพิกัดของผลเสีย และส่งสัญญาณไฟฟ้าลอจิกผ่านขา GPIO ไปควบคุมไดรเวอร์รีเลย์และวาล์วลมให้ทำงานสัมพันธ์กัน

#### ข้อที่ 14 (ข้อ 14 ในระบบ)
**คำถาม:** ขาพิน GPIO 40 ขา บนบอร์ด Raspberry Pi มีบทบาทสำคัญอย่างไรเมื่อนำมาใช้ร่วมกับระบบสายพานคัดแยก?  
- [ ] ก. เป็นช่องระบายความร้อนออกจากตัวชิปประมวลผล  
- [ ] ข. เป็นช่องสำหรับเสียบสายชาร์จแบตเตอรี่สำรอง  
- [ ] ค. เป็นช่องเชื่อมต่อสัญญาณอินเทอร์เน็ตไร้สาย  
- [x] **ง. เป็นเส้นประสาทสั่งการที่รับสัญญาณจากเซนเซอร์ และส่งกระแสไฟฟ้าไปควบคุมกลไกภายนอก (เช่น หัวพ่นลมหรือรีเลย์)**  

> **เฉลยเชิงวิเคราะห์:** GPIO (General Purpose Input/Output) ทำหน้าที่เสมือนเส้นประสาทสั่งการที่แปลงผลการตัดสินใจทางซอฟต์แวร์ของ AI ให้กลายเป็นการกระทำทางกายภาพ เช่น การรับสัญญาณเมื่อผลผลิตมาถึงหน้ากล้อง และการจ่ายแรงดันไฟฟ้า 3.3V ไปทริกเกอร์รีเลย์ของหัวพ่นลม

#### ข้อที่ 15 (ข้อ 16 ในระบบ)
**คำถาม:** กฎเหล็กข้อแรกในการติดตั้งกล้องและจัดสภาพแวดล้อมหน้างานให้ระบบ Vision ทำงานได้อย่างแม่นยำคือข้อใด?  
- [ ] ก. ปล่อยให้แสงในโรงงานมืดสนิทเพื่อให้กล้องมองเห็นชัดขึ้น  
- [ ] ข. ต้องใช้แสงธรรมชาติจากดวงอาทิตย์ที่ส่องผ่านหน้าต่างเท่านั้น  
- [x] **ค. ต้องควบคุมแสงสว่างให้คงที่ (เช่น ใช้ตู้คุมแสงหรือไฟวงแหวน LED) ห้ามใช้แสงธรรมชาติที่เปลี่ยนไปมา**  
- [ ] ง. ขยับตำแหน่งกล้องขึ้นลงทุกๆ 1 ชั่วโมง  

> **เฉลยเชิงวิเคราะห์:** ในงาน Machine Vision แสงธรรมชาติมีความแปรปรวนสูงมากตามช่วงเวลาและสภาพอากาศ ซึ่งจะทำให้ค่าตัวเลขพิกเซลของภาพเปลี่ยนไปจน AI สับสน กฎเหล็กอันดับหนึ่งคือการตัดแสงภายนอกด้วยตู้ครอบแสง (Light Enclosure) และใช้แหล่งกำเนิดแสงประดิษฐ์ที่มีความเสถียรคงที่ 100%

### 5. หมวดการคำนวณทางฟิสิกส์ การควบคุม และการบริหารจัดการโครงการ SME

#### ข้อที่ 16 (ข้อ 19 ในระบบ)
**คำถาม:** ในขั้นตอนการสื่อสารกับนักพัฒนาเรื่อง "จังหวะเวลาในการคัดแยก (Time Delay)" ตัวแปรทางกายภาพใดบ้างที่นักพัฒนาต้องนำไปใช้คำนวณร่วมกับโค้ดเพื่อให้หัวพ่นลมทำงานได้แม่นยำเป๊ะ?  
- [ ] ก. ถอดการ์ด MicroSD ออกแล้วใช้มือถือส่องแทน  
- [x] **ข. ระยะทางคงที่ระหว่างจุดตรวจจับ (กล้อง) กับจุดคัดแยก (หัวพ่นลม) หารด้วยความเร็วของสายพาน**  
- [ ] ค. ยี่ห้อของสมาร์ตโฟนของผู้จัดการโรงงาน  
- [ ] ง. อุณหภูมิและความชื้นสัมพัทธ์ในอากาศ  

> **เฉลยเชิงวิเคราะห์:** การซิงโครไนซ์เวลาใช้กฎการเคลื่อนที่เส้นตรงพื้นฐานทางฟิสิกส์ $t_{\text{delay}} = d / v$ โดยที่ $d$ คือระยะห่างระหว่างจุดศูนย์กลางภาพของกล้องไปยังหัวพ่นลม และ $v$ คือความเร็วเชิงเส้นของสายพาน การทราบตัวแปรนี้ช่วยให้โปรแกรมหน่วงเวลานับถอยหลังได้อย่างแม่นยำระดับมิลลิวินาที

#### ข้อที่ 17 (ข้อ 15 ในระบบ)
**คำถาม:** หากนักพัฒนาแนะนำให้ใช้สถาปัตยกรรมแบบ Edge AI สำหรับโรงงานชุมชน เหตุผลทางธุรกิจและวิศวกรรมข้อใดอธิบายได้ถูกต้องที่สุด?  
- [ ] ก. เพราะเป็นระบบที่ไม่ต้องใช้กล้องถ่ายภาพและไม่มีการเขียนโปรแกรมใดๆ ทั้งสิ้น  
- [ ] ข. เพราะต้องใช้อินเทอร์เน็ตความเร็วสูงระดับ 10 Gbps เชื่อมต่อไปยังเซิร์ฟเวอร์ต่างประเทศตลอดเวลา  
- [x] **ค. เพราะช่วยประหยัดต้นทุนฮาร์ดแวร์ กินไฟต่ำ(~5W), ประมวลผลรวดเร็วที่หน้างานทันที และทำงานได้แม้อินเทอร์เน็ตล่ม**  
- [ ] ง. เพราะทำให้คอมพิวเตอร์ตั้งโต๊ะขนาดใหญ่ทำงานได้ช้าลง  

> **เฉลยเชิงวิเคราะห์:** สถาปัตยกรรม Edge AI ตอบโจทย์วิสาหกิจชุมชนและ SME ได้ดีที่สุด เพราะบอร์ดเดี่ยวกินไฟต่ำเพียง 5-15W มีต้นทุนอุปกรณ์สมเหตุสมผล ประมวลผลได้รวดเร็วโดยไม่มี Latency ของเครือข่าย และยังคงทำงานคัดแยกผลผลิตได้ต่อเนื่องแม้อินเทอร์เน็ตจะขัดข้อง

#### ข้อที่ 18 (ข้อ 18 ในระบบ)
**คำถาม:** ในฐานะผู้บริหารหรือผู้จัดการโครงการ หากต้องพูดคุยและสื่อสารโจทย์กับทีมนักพัฒนา เพื่อสร้างระบบคัดแยกอัตโนมัติในงบประมาณที่คุ้มค่าสำหรับ SME ควรเลือกโครงสร้างระบบแบบใด?  
- [ ] ก. ซื้อซูเปอร์คอมพิวเตอร์เซิร์ฟเวอร์ราคาหลักล้านมาตั้งไว้กลางไร่  
- [x] **ข. ใช้ระบบ Edge AI บนคอมพิวเตอร์บอร์ดเดี่ยว (Raspberry Pi) ร่วมกับกล้องและตู้คุมแสง ประมวลผลหน้างานแบบประหยัดพลังงาน (~5W) และสั่งการกลไกผ่าน GPIO**  
- [ ] ค. เขียนจดหมายส่งไปให้ต่างประเทศช่วยประมวลผล  
- [ ] ง. จ้างพนักงานมานั่งคัดแยกด้วยมือเหมือนเดิมแต่ให้ใส่เสื้อกาวน์  

> **เฉลยเชิงวิเคราะห์:** การลงทุนสร้างระบบคัดแยกด้วย Edge AI บนบอร์ดเดี่ยวร่วมกับกล้องและตู้คุมแสง ให้ผลตอบแทนการลงทุน (ROI) สูงสุดสำหรับ SME เนื่องจากควบคุมต้นทุนได้ง่าย บำรุงรักษาสะดวก และทำงานได้จริงในสภาพแวดล้อมหน้างาน

#### ข้อที่ 19 (ข้อ 17 ในระบบ)
**คำถาม:** ข้อสรุปใดสะท้อนภาพรวมความเข้าใจเชิงคอนเซปต์ทั้งหมดของการทำระบบคัดแยกอัจฉริยะ (Smart Sorting System) ได้ถูกต้องสมบูรณ์ที่สุด?  
- [ ] ก. ซื้อแขนกลหุ่นยนต์ราคาแพงโดยไม่ต้องใช้กล้องและไม่ต้องตั้งค่าแสง  
- [x] **ข. ควบคุมแสงและฉากหลังให้เสถียร -> ใช้ Image Processing กรองขนาดและรูปทรง -> ใช้ AI ตรวจจับตำหนิผิว -> ประมวลผลด้วย Edge AI บนบอร์ดเดี่ยว และสั่งการกลไกผ่านพิน GPIO อย่างแม่นยำ**  
- [ ] ค. เขียนโค้ดสุ่มผลลัพธ์ -> ติดตั้งกลางแจ้งโดยไม่ต้องมีหลังคา -> รอให้ฝนตกแล้วปิดระบบ  
- [ ] ง. ถ่ายภาพด้วยมือถือ -> โพสต์ลงโซเชียล -> รอคนมากดไลค์แล้วค่อยคัดแยกผลไม้  

> **เฉลยเชิงวิเคราะห์:** นี่คือสายการผลิตอัจฉริยะที่ถูกต้องตามหลักวิศวกรรมแบบบูรณาการ เริ่มต้นจากการคุมสภาพแวดล้อมทางแสง $\rightarrow$ ใช้การประมวลผลภาพเบื้องต้นคัดกรองมิติภายนอก $\rightarrow$ ส่งต่อให้ AI วินิจฉัยรอยโรคระดับลึก $\rightarrow$ และประมวลผลสั่งการกลไกทางกายภาพผ่าน GPIO ได้อย่างแม่นยำสมบูรณ์แบบ
