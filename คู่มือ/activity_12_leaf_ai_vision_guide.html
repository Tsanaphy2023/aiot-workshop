คู่มือมาตรฐานสำหรับวิทยากร ผู้ช่วยสอน (TA) และผู้เรียน — โครงการ Smart Farm AIoT (มรภ.รำไพพรรณี × ม.เชียงใหม่)

📌 1. บทนำและแนวคิดวิศวกรรม (Vision AI & Edge Classification)

ในกิจกรรมนี้ ผู้เรียนจะได้ต่อยอดจากระบบโทรมาตรเชิงตัวเลข (Scalar Telemetry) สู่ ระบบคอมพิวเตอร์วิทัศน์และปัญญาประดิษฐ์ฝังตัว (Embedded Computer Vision & Edge AI) เพื่อตรวจจับความผิดปกติของใบพืช วินิจฉัยโรคระบาด และคัดแยกคุณภาพผลผลิตทางการเกษตร 6 ชนิด ได้แก่ ข้าวโพด, กาแฟ, มันฝรั่ง, ส้ม, มะม่วง และกล้วย รวม 18 คลาส จากชุดข้อมูลภาพถ่ายจริง 5,846 ภาพ

หัวใจสำคัญในกิจกรรมที่ 12:
  • Stratified Train / Val / Test: การแบ่งข้อมูลอย่างสมดุล (70% ฝึกสอน, 15% ตรวจสอบ, 15% ทดสอบจริง) ป้องกันปัญหาข้อมูลเอียง (Imbalance)
  • Depthwise Separable Convolutions: โครงสร้างโมเดล MobileNetV2 และ LeafNet ที่ลดการคำนวณลง 8-9 เท่า เหมาะสำหรับบอร์ด Edge AI
  • Dual Execution Runtime: เลือกได้ว่าจะรันฝึกสอนบนเครื่องคอมพิวเตอร์จริงผ่าน Apple Silicon MPS หรือเปิดรันบน Google Colab GPU T4 ฟรี

📋 4. ขั้นตอนการลงมือปฏิบัติทีละขั้น (Step-by-Step Hands-on)
ขั้นตอนที่ 12.1 สำรวจข้อมูลและแบ่งสัดส่วน Stratified Train/Val/Test

เปิดไปที่หน้าเว็บพอร์ทัลแท็บ 01. สำรวจ & แบ่งข้อมูล เลือกชนิดพืชเป้าหมาย (เช่น ข้าวโพด 4 คลาส 3,924 ภาพ) ปรับสัดส่วน Slider 70% : 15% : 15% แล้วกดปุ่ม "⚡ สั่งรันการแบ่งชุดข้อมูลจริง" สังเกตตารางสรุปจำนวนภาพและคลังตัวอย่างภาพถ่ายจริง

ขั้นตอนที่ 12.2 เลือกสถาปัตยกรรมโครงข่ายประสาทเทียม

คลิกแท็บ 02. เลือกโมเดล & ตั้งค่า เพื่อเปรียบเทียบสเปกของโมเดล:

  • MobileNetV2: แนะนำสำหรับบอร์ด Raspberry Pi / Web (3.5M พารามิเตอร์)
  • ResNet18: โครงข่าย Residual มาตรฐานงานวิจัย ให้ความแม่นยำสูง (11.7M พารามิเตอร์)
  • LeafNet: Custom Lightweight CNN ขนาดเบาพิเศษ (1.2M พารามิเตอร์) สำหรับบอร์ด ESP32
ขั้นตอนที่ 12.3 ปฏิบัติการฝึกสอนโมเดลจริง (Live Training)

คลิกแท็บ 03. ฝึกสอนโมเดลจริง ผู้เรียนสามารถเลือกฝึกสอนได้ 2 รูปแบบ:

  • รันบนเครื่องคอมพิวเตอร์จริง: กดปุ่ม "▶ เริ่มต้นฝึกสอนบนเครื่องจริง" พร้อมดู Terminal Log สด
  • รันบน Google Colab: กดปุ่มสีส้ม "🚀 เปิดรันใน Google Colab" เพื่อใช้ GPU Tesla T4 ฟรี
python scripts/02_train.py --crop corn --backbone mobilenet_v2 --epochs 15 --batch_size 32
ขั้นตอนที่ 12.4 ประเมินผลบน Test Set และอ่านแผนภาพความสับสน

คลิกแท็บ 04. ประเมินผล & Matrix กดปุ่ม "🔍 สั่งประเมินผลบน Test Set" ระบบจะดึงภาพ 15% ที่ไม่เคยผ่านการเทรนมาทดสอบ เพื่อคำนวณ Test Accuracy, Macro F1, และสร้างภาพ Confusion Matrix Heatmap

ขั้นตอนที่ 12.5 ห้องทดลองทำนายภาพโรคพืชสด (Inference Playground)

คลิกแท็บ 05. ทดสอบทำนายภาพ ลากไฟล์ภาพใบไม้มาวางในกล่อง Dropzone หรือคลิกเลือกจากคลังตัวอย่าง แล้วกดปุ่ม "✨ วิเคราะห์และทำนายโรคพืช" ระบบจะแสดงชื่อโรคที่วินิจฉัยได้ แถบเปอร์เซ็นต์ความมั่นใจ และอันดับ Top-3 Classes

ขั้นตอนที่ 12.6 ส่งออกโมเดลสำหรับ Edge AI (ONNX / TorchScript)

คลิกแท็บ 06. ส่งออก Edge AI กดปุ่ม "💾 แปลงและส่งออกโมเดล" เพื่อรับไฟล์ .onnx และ .pt พร้อมดาวน์โหลดนำไปติดตั้งบนบอร์ดสมาร์ทฟาร์มจริง

⚠️ 5. จุดที่มักผิดพลาดและการแก้ปัญหา (Troubleshooting)
ปัญหาที่พบบ่อย สาเหตุ แนวทางแก้ไข
กดปุ่มบนเว็บแล้วไม่ตอบสนอง Apache / XAMPP หรือ Python Server ออฟไลน์ ตรวจจุดสถานะขวาบนต้องเป็นสีเขียว หากสีแดงให้เปิด XAMPP Control Panel แล้ว Start Apache
เทรนบนเครื่องช้ามาก เครื่องคอมพิวเตอร์ไม่มี GPU เร่งการประมวลผล ให้คลิกปุ่มสีส้มเพื่อสลับไปรันบน Google Colab (GPU Tesla T4 ฟรี)
โมเดล Overfitting (Train สูง แต่ Val ต่ำ) โมเดลจำข้อสอบฝึกสอนแต่ไม่สามารถปรับตัวกับภาพใหม่ เปิดใช้งาน Data Augmentation (สุ่มหมุน, สุ่มพลิก) และระบบ Early Stopping
