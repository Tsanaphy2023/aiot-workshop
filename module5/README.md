## 💡 สรุปสาระสำคัญของเนื้อหา

### 1. ภาพดิจิทัลคืออะไร? (Digital Image Representation)
* ภาพถ่ายในคอมพิวเตอร์เปรียบเสมือน **"กระดานสมุดกราฟ"** ที่ประกอบด้วยช่องสี่เหลี่ยมเล็กๆ เรียกว่า **พิกเซล (Pixel)**
* แต่ละพิกเซลเก็บค่าความสว่างเป็นตัวเลขระหว่าง **0 - 255** (0 = ดำสนิท, 255 = ขาวสว่างสุด)
* คอมพิวเตอร์ประมวลผลภาพผ่าน **เมทริกซ์ตัวเลข 2 มิติ (Grayscale)** หรือ **3 มิติ (Color Image: 3 Channels)**

### 2. ทำไมใช้ระบบสี RGB อย่างเดียวถึงไม่พอในงานเกษตร?
* ในระบบ **RGB (Red, Green, Blue)** ความสว่างและสีจะปะปนอยู่ในช่องสัญญาณเดียวกัน
* เมื่อแสงแดดหรือแสงตกกระทบผลไม้ไม่สม่ำเสมอ เกิดเงาตกกระทบ ค่าตัวเลข RGB จะเปลี่ยนไปทันที ทำให้คอมพิวเตอร์สับสนว่าส่วนที่เป็นเงาคือตำหนิหรือสีดำ ไม่ใช่ผลสุก
* **ทางออก:** แปลงปริภูมิสีเป็น **HSV (Hue, Saturation, Value)**
  * **Hue (H):** เฉดสีจริง (0 - 360 องศา) แยกออกจากความสว่างโดยสิ้นเชิง
  * **Saturation (S):** ความอิ่มตัวหรือความสดของสี
  * **Value (V):** ระดับความสว่างของแสง
* เมื่อใช้โหมด HSV สามารถกำหนดช่วง **Color Threshold** เพื่อตรวจจับและคัดแยกความสุกของผลไม้ (เช่น มะเขือเทศ ส้ม) ได้อย่างแม่นยำแม้ในสภาพแสงธรรมชาติที่ไม่คงที่

## 3. สรุปประเด็นข้อสอบสำคัญ (Quiz Highlights)
* **รูปแบบที่คอมพิวเตอร์มองเห็นภาพถ่ายดิจิทัล:**
  * คอมพิวเตอร์มองเห็นภาพเป็น **"ตารางตัวเลข หรือ เมทริกซ์ของตัวเลข (Matrix of Numbers / Pixel Grid)"** 
  * แต่ละจุดพิกเซลเก็บค่าตัวเลข $0 - 255$ (0 = มืดสุด, 255 = สว่างสุด)
  * ภาพขาวดำเป็นเมทริกซ์ 2 มิติ ส่วนภาพสี (RGB) เป็นเมทริกซ์ 3 มิติ (3 Channels)
* **ปัญหาของระบบสี RGB เมื่อเจอแสงเงา:**
  * **ค่า RGB วัดค่าสีรวมกับความสว่าง:** ทำให้เมื่อมีเงาตกกระทบ ค่าตัวเลข RGB ดรอปลงเข้าใกล้ 0 คอมพิวเตอร์จะสับสนคิดว่าเป็นสีดำ รอยช้ำ หรือตำหนิ จึงต้องแก้ด้วยการแปลงเป็นระบบ **HSV** เพื่อแยกเฉดสี (Hue) ออกจากความสว่าง (Value)
