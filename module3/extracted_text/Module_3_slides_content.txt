[หน้า 5]
การคำนวณปริมาณน้ำและอัตราการไหล:
เริ่มต้นจากการหาความต้องการน้ำของพืช (Crop Water Requirement) เพื่อกำหนดอัตราการไหลรวม (Flow Rate) ของระบบ
การวางระบบน้ำ ต้องทราบปริมาณน้ำที่พืชต้องการต่อวัน โดยใช้วิธีคำนวณอัตราการไหลจากความต้องการน้ำสูงสุด (Peak Water Demand):
สูตร:
Q = (A * ETc) / (T * Eff)
- Q: อัตราการไหลที่ต้องการ (m^3/hr หรือ L/min)
- A: พื้นที่เพาะปลูก (ตารางเมตร)
- ETc: อัตราการคายน้ำของพืช (mm/day)
- Eff: ประสิทธิภาพระบบให้น้ำ (หยด 90%, สปริงเกลอร์ 75%)
- T: ระยะเวลาการให้น้ำแต่ละวัน (hr/day)

[หน้า 6]
ไฮดรอลิกส์และการเลือกขนาดท่อ:
1. ความเร็วของน้ำในท่อ (Velocity)
ความเร็วของน้ำที่เหมาะสมในท่อเมนและท่อย่อยควรอยู่ที่ 1.0 - 2.0 m/s
- ถ้าน้ำไหลช้าเกินไป (< 0.5 m/s): สิ้นเปลืองค่าท่อที่มีขนาดใหญ่เกินจำเป็น
- ถ้าน้ำไหลเร็วเกินไป (> 2.5 m/s): เกิดแรงดันค้อน (Water Hammer) และความต้านทานสูง
2. การคำนวณหน้าตัดท่อ (A = Q / v)
หาขนาดเส้นผ่านศูนย์กลางท่อภายในจากสูตรต่อเนื่องของการไหล:
Q = A * v = (pi * d^2 / 4) * v
ช่วยในการเลือกขนาดท่อ PVC หรือ HDPE ให้เหมาะกับอัตราการจ่ายน้ำของแต่ละโซน

[หน้า 7]
การสูญเสียแรงดันในท่อ:
เมื่อน้ำไหลผ่านท่อจะเกิดแรงเสียดทาน ทำให้แรงดันปลายทางลดลง คำนวณได้จากสูตร Hazen-Williams:
hf = (10.67 * L * Q^1.852) / (C^1.852 * D^4.87)
ปัจจัยที่มีผลต่อแรงดันตก:
ยิ่งท่อยาว (L) ท่อเล็ก (D) หรืออัตราไหลสูง (Q) แรงดันจะยิ่งสูญเสียมาก ข้อต่อและวาล์วต้องเผื่อ Minor Loss อีกประมาณ 10-20%

[หน้า 8]
รายละเอียดตัวแปรสูตร Hazen-Williams:
- hf = การสูญเสียความดัน (Head Loss) ในหน่วยเมตร (m)
- L = ความยาวของท่อ ในหน่วยเมตร (m)
- Q = อัตราการไหลของน้ำ ในหน่วยลูกบาศก์เมตรต่อวินาที (m^3/s)
- C = ค่าสัมประสิทธิ์ความเรียบของผิวท่อ (Hazen-Williams Coefficient)
- D = เส้นผ่านศูนย์กลางภายในของท่อ ในหน่วยเมตร (m)
ค่าสัมประสิทธิ์ความเรียบของท่อ (C):
- ท่อพีวีซี (PVC) / ท่อทองแดง: C = 130 - 150
- ท่อเหล็กชุบสังกะสี (Galvanized Steel): C = 120
- ท่อเหล็กหล่อ (Cast Iron): C = 100 - 130
- ท่อคอนกรีต: C = 100 - 140

[หน้า 9]
ส่วนประกอบของ TDH ในการเลือกปั๊ม (Total Dynamic Head):
เฮดรวมคือพลังงานแรงดันทั้งหมดที่ปั๊มต้องสร้างขึ้น เพื่อส่งน้ำไปยังจุดใช้งานปลายทางได้อย่างสมบูรณ์:
TDH = Hs + Hd + Hf + Hop
- Hs (Static Suction): ระยะความสูงฝั่งสูบน้ำ
- Hd (Static Discharge): ระยะความสูงจากปั๊มถึงจุดสูงสุด
- Hf (Friction Loss): แรงดันสูญเสียรวมในท่อและข้อต่อ
- Hop (Operating Pressure): แรงดันใช้งานของมินิสปริงเกลอร์หรือหัวหยด

[หน้า 10]
หลักการเลือกปั๊มน้ำให้เหมาะกับงาน:
1. เทียบคู่ Q และ TDH: นำค่า Q (อัตราไหล) และ TDH ที่คำนวณได้ ไปเปิดกราฟ Pump Performance Curve เพื่อหาจุดทำงาน (Operating Point) ของปั๊ม
2. เลือกประเภทปั๊ม:
   - หอยโข่งแรงดันสูง (Centrifugal): เหมาะกับระบบสปริงเกลอร์
   - หอยโข่งปริมาณน้ำมาก: เหมาะกับระบบน้ำหยดแปลงใหญ่
3. ประสิทธิภาพปั๊ม (Efficiency): เลือกปั๊มที่จุดทำงานตกอยู่ในช่วง Best Efficiency Point (BEP) ของกราฟ เพื่อประหยัดพลังงานไฟฟ้ามากที่สุด

[หน้า 11]
การคำนวณกำลังมอเตอร์ปั๊มน้ำ:
สูตรกำลังมอเตอร์:
P (kW) = (rho * g * Q * TDH) / (3600 * eta)
โดย rho คือความหนาแน่นน้ำ (1000 kg/m^3), g = 9.81 m/s^2, Q คือ ลบ.ม./ชม., eta คือประสิทธิภาพปั๊มรวม (ประมาณ 0.60 - 0.75)
ตัวอย่างระบบ:
- ระบบน้ำหยด (20 m^3/h, TDH 18m) -> 2.0 HP (1.5 kW)
- มินิสปริงเกลอร์ (25 m^3/h, TDH 28m) -> 4.0 HP (3.0 kW)
- สปริงเกลอร์ใหญ่ (30 m^3/h, TDH 42m) -> 7.5 HP (5.5 kW)
- ระบบสเปรย์แรงดันสูง (35 m^3/h, TDH 55m) -> 11.0 HP (8.2 kW)

[หน้า 12]
ขั้นตอนการออกแบบระบบให้น้ำ 5 ขั้น:
1. สังเกตพื้นที่: สำรวจแปลง คำนวณความต้องการน้ำของพืช และแบ่งโซนการจ่ายน้ำ
2. เลือกหัวจ่าย: กำหนดประเภทหัวหยด/สปริงเกลอร์ แรงดันใช้งาน และอัตราจ่ายน้ำ
3. ขนาดท่อน้ำ: คำนวณท่อเมน/ท่อย่อย ตามอัตราไหลและความเร็วไม่เกิน 2 m/s
4. คำนวณ TDH: รวมความสูง แรงดันใช้งาน และ Head Loss ในท่อทั้งหมด
5. เลือกปั๊มและตู้: เลือกปั๊มน้ำ ติดตั้งโซลินอยด์วาล์ว และระบบบอร์ดสั่งการ IoT

[หน้า 13]
อุปกรณ์ระบบรดน้ำ:
1. เซนเซอร์วัดปริมาณน้ำฝน: ถ้าฝนตกเพียงพอ ไม่ต้องรดน้ำซ้ำ สามารถใช้เซนเซอร์วัดอุณหภูมิความชื้นในอากาศแทนได้ ไม่จำเป็นต้องวัดความชื้นดิน
2. Solenoid Valves: วาล์วไฟฟ้า 24VAC หรือ 12VDC ทำหน้าที่เปิดจ่ายน้ำแยกตามโซนที่คำนวณไว้ เพื่อลดขนาดปั๊มน้ำและอัตราไหลรวม
3. IoT Controller & Dashboard: ไมโครคอนโทรลเลอร์ (ESP32 / Arduino / PLC) ประมวลผลร่วมกับ Dashboard บันทึกปริมาณน้ำและตั้งเวลาอัตโนมัติ
