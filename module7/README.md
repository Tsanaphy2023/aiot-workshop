## 💡 สรุปสาระสำคัญของเนื้อหา

### 1. ปัญหาของการคัดแยกผลผลิตด้วยแรงงานมนุษย์ vs การใช้สายตากล้องอัตโนมัติ
* **แรงงานมนุษย์:**
  * เกิดความเหนื่อยล้าเมื่อทำงานต่อเนื่องเป็นเวลานาน
  * มาตรฐานการตัดสินใจตกลงตามเวลาและสภาพแวดล้อม
  * มีโอกาสหลุดรอดของผลผลิตที่มีตำหนิปนไปกับสินค้าเกรดพรีเมียม
* **ระบบกล้องอัจฉริยะบนคอมพิวเตอร์บอร์ดเดี่ยว (SBC):**
  * ให้ความสม่ำเสมอในการตัดสินใจ 100%
  * ตัดสินใจด้วยความเร็วสูงแบบเรียลไทม์ที่ระดับเสี้ยววินาที
  * มีหลักฐานบันทึกภาพถ่ายและสถิติคุณภาพผลผลิตสำหรับตรวจสอบย้อนกลับ (Traceability)

### 2. สถาปัตยกรรมระบบคัดแยกผลผลิตอัตโนมัติชุมชน
* **ฮาร์ดแวร์ประมวลผล (SBC):** เช่น Raspberry Pi 4/5 หรือ NVIDIA Jetson Nano/Orin
* **ระบบรับภาพ (Camera Vision):** กล้อง USB Camera หรือ MIPI CSI Camera ติดตั้งเหนือสายพาน พร้อมชุดควบคุมแสงสว่างสม่ำเสมอ (Light Box)
* **ระบบส่งกำลังและคัดแยก (Actuation):**
  * สายพานลำเลียง (Conveyor Belt) พร้อมมอเตอร์ปรับสปีด
  * แขนกลผลัก (Pneumatic Piston / Push Cylinder) หรือ Flap Diverter แยกผลผลิตลงถังบรรจุตามเกรด
  * การเชื่อมต่อบอร์ด SBC เข้ากับรีเลย์และ Solenoid Valve ขับลมเพื่อดีดผลผลิตที่ไม่ได้มาตรฐานออก

## 3. สรุปประเด็นข้อสอบสำคัญ (Quiz Highlights)
* **อุปกรณ์สมองกลขนาดจิ๋วที่ติดตั้งหน้างานสำหรับรันระบบ Edge AI:**
  * **คอมพิวเตอร์บอร์ดเดี่ยว (Single Board Computer: SBC)** เช่น Raspberry Pi, NVIDIA Jetson Nano/Orin
  * ทำหน้าที่เป็น Edge Computing ประมวลผลภาพจากกล้อง รันโมเดล AI คัดแยกผลผลิตและควบคุมแขนกลดีดสินค้าได้แบบ Real-time หน้างาน โดยไม่ต้องพึ่งพาอินเทอร์เน็ต
* **เป้าหมายหลักของการใช้ Image Processing (Rule-based):**
  * **สำหรับการวัดขนาด (S-M-L), นับพื้นที่ และคัดกรองรูปทรงพื้นฐานอย่างรวดเร็วโดยไม่ต้องใช้ AI ซับซ้อน:** ประมวลผลได้รวดเร็วระดับมิลลิวินาที กินทรัพยากรต่ำ เหมาะกับการคัดแยกมิติทางกายภาพ
* **ลักษณะการทำงานของ AI ในการตรวจหารอยโรค/รอยช้ำ:**
  * **เหมือนการสอนงานพนักงานใหม่ โดยการป้อนรูปตัวอย่างของดีและมีตำหนิให้ AI จดจำแพทเทิร์นได้เอง:** เพราะแผลหรือรอยโรคมีรูปทรงไม่แน่นอน ไม่สามารถเขียนสูตรตายตัวได้ ต้องให้ Deep Learning สกัดลักษณะเด่นและเรียนรู้รูปแบบด้วยตัวเอง
