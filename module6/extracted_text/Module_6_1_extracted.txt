4. เจาะลึกคําสัง model.train() ใน Ultralytics YOLO
ปรับแต่งพารามิเตอร์สําคัญ: data, epochs, imgsz, batch

💻 คำสังเริมฝกอบรม AI
from ultralytics import YOLO

# 1. โหลดโมเดลตั้งต้น (Pre-trained Weights)
model = YOLO('yolov8n.pt')
# 2. เริ่มต้นเทรนโมเดล
results = model.train(
data=f"{dataset.location}/data.yaml",
epochs=25, # จำนวนรอบการเรียนรู้
imgsz=640, # ขนาดภาพที่ใช้เทรน
batch=16, # จำนวนภาพต่อรอบ
device=0 # ใช้ GPU การ์ดจอ
)

⚙️ ความหมายของตัวแปร (เหมือนตังค่าเครืองจักร)
data=... : ชี้ตําแหน่งไฟล์ data.yaml ทีบอกโฟลเดอร์รูปภาพ
epochs=25 : จำนวนรอบที่ AI เปิดดูรูปทั้งหมดซ้ำๆ (25 รอบใช้เวลา
~3 นาที เหมาะกับการเรียนการสอน)
imgsz=640 : ย่อ-ขยายภาพทุกใบให้มีขนาด 640x640 พิกเซลก่อน
เข้าสมองกล
batch=16 : ป้อนภาพให้ GPU ทีละ 16 รูปพร้อมกัน
device=0 : ระบุให้คํานวณบนการ์ดจอ T4 GPU ของ Google Colab

6. สั่ง AI ลงสนามตรวจจับด้วย model.predict()
ทดสอบนำภาพ/วิดีโอใหม่หน้างานมาให้โมเดลตีกรอบชีเปา

💻 คำสังทดสอบภาพ (Inference)

🎯 ค่าทีได้จากผลการ Predict แต่ละลูก
AI จะส่งข้อมูลตัวเลขออกมา 3 อย่าง เพือส่งต่อให้กลไกโรงงาน:

# 1. โหลดสมองกลที่ดีทีสุดทีเราเทรนเสร็จ
best_model = YOLO('runs/detect/train/weights/best.pt')
# 2. สั่งตรวจจับภาพชุดทดสอบ (Test Set)
results = best_model.predict(
source=f"{dataset.location}/test/images",
conf=0.5,
# เอาเฉพาะที่มั่นใจเกิน 50%
save=True
# บันทึกภาพทีตีกรอบแล้ว
)

1. Bounding Box Coordinates (xyxy):
พิกัดสี่เหลี่ยม [x_min, y_min, x_max, y_max] เพื่อระบุ
ตำแหน่งแผลบนสายพาน
2. Class Label:
บอกว่าเปน 0 (healthy) หรือ 1 (rotten)
3. Confidence Score:
ความมั่นใจ เช่น 0.94 (94%)
