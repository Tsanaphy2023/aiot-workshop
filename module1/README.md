# Module 1: เทคโนโลยีเซนเซอร์วัดค่าสภาพแวดล้อมและชีวภาพ
**(Bio-Environmental Sensing & Protocols)**

## 1. คำอธิบายเนื้อหาและหัวข้อการเรียนรู้
หลักสูตรย่อยนี้มุ่งเน้นการทำความเข้าใจและการประยุกต์ใช้เซนเซอร์ในภาคการเกษตรอย่างครอบคลุม แบ่งเป็น 11 หัวข้อย่อยหลัก:

1. **รู้จักเซนเซอร์สำหรับงานเกษตร:** เรียนรู้ประเภทและบทบาทของเซนเซอร์ที่ใช้ในการผลิตพืช ปศุสัตว์ ประมง และหลังการเก็บเกี่ยว
2. **ตรวจวัดสภาพแวดล้อมอย่างแม่นยำ:** เข้าใจการวัดแสง อุณหภูมิ ความชื้น ลม ฝน และความกดอากาศที่มีผลต่อการผลิต
3. **วิเคราะห์ดินและธาตุอาหาร:** เรียนรู้การใช้เซนเซอร์ตรวจวัดความชื้นในดิน ค่า pH และธาตุอาหาร NPK
4. **เลือกเซนเซอร์ให้เหมาะกับพื้นที่ใช้งาน:** พิจารณาคุณสมบัติของอุปกรณ์ให้สอดคล้องกับบริบทของสวน ไร่ และฟาร์ม
5. **เชื่อมต่อเซนเซอร์กับบอร์ดควบคุม:** ทำความเข้าใจการเชื่อมต่อกับไมโครคอนโทรลเลอร์เพื่อรับและประมวลผลข้อมูล
6. **เรียนรู้ระบบสื่อสารของเซนเซอร์:** ทำความรู้จักโพรโทคอลสำคัญ เช่น 1-Wire, I2C, SPI และ RS485 (Modbus RTU)
7. **อ่านและแปลผลข้อมูลจากเซนเซอร์:** ฝึกทำความเข้าใจค่าที่วัดได้และนำไปใช้ติดตามสภาพแวดล้อมการผลิต
8. **บันทึกข้อมูลเพื่อการวิเคราะห์:** เรียนรู้หลักการ Data Logging เพื่อเก็บข้อมูลสำหรับติดตามแนวโน้มและวิเคราะห์ในขั้นต่อไป
9. **สอบเทียบเซนเซอร์ให้แม่นยำ:** เรียนรู้การ Calibration เพื่อเพิ่มความถูกต้องและความน่าเชื่อถือของข้อมูล
10. **แก้ปัญหาที่พบบ่อยในการใช้งานจริง:** ทำความเข้าใจปัญหาจากการต่อวงจร การตั้งค่า และข้อจำกัดของสภาพแวดล้อม
11. **ต่อยอดสู่ระบบเกษตรอัจฉริยะ:** เตรียมข้อมูลจากเซนเซอร์เพื่อเชื่อมต่อไปยังระบบบันทึกข้อมูล การสื่อสาร และ AIoT ในโมดูลถัดไป

## 5. การคำนวณอุณหภูมิสะสม (Growing Degree Days: GDD) และอุณหภูมิฐาน ($T_{base}$)

อุณหภูมิสะสม (Growing Degree Days หรือ GDD) หรือเวลาเชิงความร้อน (Thermal Time) คือดัชนีชี้วัดพลังงานความร้อนที่พืชได้รับเหนืออุณหภูมิวิกฤตขั้นต่ำ ใช้ประเมินอัตราการเจริญเติบโตและการเปลี่ยนผ่านระยะฟีโนโลยี (เช่น การงอก การบานของดอก การสะสมแป้ง และการสุกแก่เก็บเกี่ยว) แทนการนับวันตามปฏิทิน

### 5.1 สูตรและสมการการคำนวณ GDD

1. **วิธีเฉลี่ยมาตรฐาน (Simple Averaging / FAO-56 Method):**
   $$GDD = \max\left(0, \frac{T_{max} + T_{min}}{2} - T_{base}\right)$$
   *(หากค่าเฉลี่ยต่ำกว่า $T_{base}$ จะบันทึกค่าเป็น 0)*

2. **วิธีดัดแปลงจำกัดขอบเขต (Modified Sine / Cut-off Method):**
   $$T_{min}^* = \max(T_{min}, T_{base}), \quad T_{max}^* = \min(T_{max}, T_{upper})$$
   $$GDD = \max\left(0, \frac{T_{max}^* + T_{min}^*}{2} - T_{base}\right)$$

3. **วิธีอินทิเกรตรายชั่วโมงตามเวลาจริง (Hourly Thermal Time) สำหรับเซนเซอร์ AIoT:**
   $$GDD_{daily} = \frac{1}{24} \sum_{h=1}^{24} \max\left(0, \min(T_h, T_{upper}) - T_{base}\right)$$

### 5.2 ฐานข้อมูลอุณหภูมิฐาน ($T_{base}$), อุณหภูมิเพดาน ($T_{upper}$) และความต้องการ GDD ของพืชเศรษฐกิจ

## 6. ฟิสิกส์แรงดึงน้ำในดิน (Soil Water Tension / Matric Potential)

แรงดึงน้ำในดิน คือแรงที่อนุภาคเม็ดดินยึดเหนี่ยวโมเลกุลน้ำไว้ด้วยแรงแคปิลลารีและแรงดูดซับ ยิ่งดินแห้งแรงดึงยิ่งสูง รากพืชยิ่งต้องออกแรงดูดน้ำมาก

![แผนผังอธิบายแรงดึงน้ำในดิน 3 ระยะหลัก](/Applications/XAMPP/xamppfiles/htdocs/cmu_aiot/module1/soil_water_tension_infographic.jpg)

### สรุป 3 สภาวะทางฟิสิกส์สำคัญ:
1. **Saturation (จุดอิ่มตัวด้วยน้ำ, $0\text{ kPa}$):** ดินแฉะ น้ำขัง ช่องว่างทุกช่องเต็มไปด้วยน้ำ พืชขาดออกซิเจน เสี่ยงรากเน่า
2. **Field Capacity & Optimal Zone (ความจุความชื้นสนาม, $10 - 33\text{ kPa}$):** ดินอุ้มน้ำไว้ได้สูงสุดหลังจากน้ำส่วนเกินไหลทิ้ง มีสมดุลระหว่างน้ำและอากาศดีที่สุด รากพืชดูดซึมธาตุอาหารได้คล่องตัวสูงสุด
3. **Permanent Wilting Point (จุดเหี่ยวถาวร, $1,500\text{ kPa}$):** ดินแห้งผาก อนุภาคดินยึดน้ำไว้แน่นเกินกว่ารากพืชจะดึงได้ พืชเหี่ยวเฉาถาวรและแห้งตาย
