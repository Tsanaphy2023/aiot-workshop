# ⚡ สถาปัตยกรรมสะพานเชื่อม RS485 Modbus RTU โพรบวัดดิน NPK สู่เครือข่าย Zigbee 3.0 (Industrial RS485 to Zigbee Bridge)

---

## 1. ปัญหาและความจำเป็นทางวิศวกรรม (The Engineering Challenge)

โพรบวัดดินระดับอุตสาหกรรมในปัจจุบัน เช่น **โพรบวัดดิน 7-in-1 (Soil Moisture, Temperature, EC, pH, N, P, K)** นิยมใช้โปรโตคอลมาตรฐานอุตสาหกรรม **RS485 Modbus RTU** ซึ่งมีจุดเด่นคือ:
* ทนสัญญาณรบกวนในดินและแปลงเกษตรได้ดีเยี่ยม
* ใช้สายสัญญาณยาวได้ถึงหลายร้อยเมตร
* แต่ **"ไม่มีชิปวิทยุไร้สายในตัว และกินไฟสูง (ต้องการไฟเลี้ยง 5V – 24V DC)"**

การนำเซนเซอร์เหล่านี้เข้ามาเป็นส่วนหนึ่งของเครือข่ายไร้สาย Zigbee 3.0 จึงต้องใช้สถาปัตยกรรม **"Zigbee Modbus Bridge Node"** โดยใช้ไมโครคอนโทรลเลอร์ **ESP32-C6** ร่วมกับวงจรสวิตช์พลังงาน (Power Gating)

---

## 2. แผนผังวงจรฮาร์ดแวร์ (Hardware Schematic Architecture)

```
                       [ แบตเตอรี่ LiFePO4 3.2V 3200mAh / แผงโซลาร์ ]
                                       │
                   ┌───────────────────┴───────────────────┐
                   │                                       │
            (3.3V LDO RT9013)                     (DC-DC Boost 12V)
                   │                                       │
                   ▼                               [ P-Channel MOSFET ]
           ┌──────────────┐                        (สวิตช์เปิดไฟเฉพาะตอนวัด)
           │   ESP32-C6   │                                │
           │  (MCU+Zigbee)│                                ▼
           │              │                   ┌─────────────────────────┐
           │ GPIO 16 (TX) ├────► [ SP3485 ] ──┤ RS485 A (+)             │
           │ GPIO 17 (RX) ◄────┤ (3.3V RS485) │ RS485 B (-)             │
           │ GPIO 18 (EN) ├────┤ Transceiver  │ VCC (+12V DC)           │
           │              │                   │ GND                     │
           │ GPIO 19 (PWR)├───────────────────┤ โพรบวัดดิน 7-in-1 NPK    │
           └──────────────┘                   └─────────────────────────┘
```

### รายการอุปกรณ์หลัก:
1. **ไมโครคอนโทรลเลอร์:** ESP32-C6-WROOM-1 หรือโมดูล Seeed Studio XIAO ESP32C6 (มี Zigbee 3.0 + RISC-V 32-bit core ในตัว)
2. **ชิปแปลงสัญญาณ RS485:** **SP3485** หรือ **MAX3485** (รองรับแรงดันลอจิก 3.3V ตรงกับ ESP32-C6 โดยไม่ต้องใช้วงจร Level Shifter)
3. **วงจรจ่ายไฟโพรบ:** Boost Converter แปลง 3.2V $\rightarrow$ 12V DC โดยมี P-MOSFET (เช่น AO3401) เป็นสวิตช์ตัดไฟโพรบเมื่อหลับ

---

## 3. ตารางรีจิสเตอร์ Modbus RTU (Register Mapping)

โพรบ 7-in-1 ส่วนใหญ่ (Baud rate 4800 หรือ 9600 bps, 8-N-1, Slave ID = `0x01`):
* **คำสั่ง Modbus Function:** `0x03` (Read Holding Registers)
* **Start Address:** `0x0000`, **Length:** 7 Registers

| Register Address | ข้อมูลที่อ่านได้ | สเกลตัวคูณ (Scale) | ตัวอย่างค่า Hex | ค่าที่แปลงได้จริง |
| :--- | :--- | :--- | :--- | :--- |
| `0x0000` | ความชื้นในดิน (Soil Moisture) | $\times 10$ ($0.1\%$) | `0x01E0` (480) | **48.0 %** |
| `0x0001` | อุณหภูมิดิน (Soil Temp) | $\times 10$ ($0.1^\circ C$) | `0x010E` (270) | **27.0 °C** |
| `0x0002` | การนำไฟฟ้าดิน (Soil EC) | $\times 1$ ($1\,\mu S/cm$) | `0x0352` (850) | **850 µS/cm** |
| `0x0003` | ความเป็นกรด-ด่างดิน (Soil pH) | $\times 10$ ($0.1\,pH$) | `0x0041` (65) | **6.5 pH** |
| `0x0004` | ไนโตรเจน (Nitrogen - N) | $\times 1$ ($1\,mg/kg$) | `0x0028` (40) | **40 mg/kg** |
| `0x0005` | ฟอสฟอรัส (Phosphorus - P) | $\times 1$ ($1\,mg/kg$) | `0x0014` (20) | **20 mg/kg** |
| `0x0006` | โพแทสเซียม (Potassium - K) | $\times 1$ ($1\,mg/kg$) | `0x003C` (60) | **60 mg/kg** |

---

## 4. ลำดับการทำงานเพื่อประหยัดพลังงาน (Firmware State Machine)

```
[ ตื่นจาก Deep Sleep (ทุก 10 นาที) ]
                │
                ▼
[ ดึงขา GPIO 19 LOW เพื่อจ่ายไฟ 12V ให้โพรบ NPK ]
                │
                ▼
[ หน่วงเวลา 150 ms เพื่อให้เซนเซอร์ Stabilization ]
                │
                ▼
[ ส่งคำสั่ง Modbus Frame: 01 03 00 00 00 07 04 08 ]
                │
                ▼
[ รับข้อมูล Response 19 ไบต์ และตรวจสอบ CRC-16 ]
                │
                ▼
[ ดึงขา GPIO 19 HIGH เพื่อตัดไฟ 12V ทันที (Power Off Sensor) ]
                │
                ▼
[ จัดโครงสร้าง ZCL Attributes และส่งผ่าน Zigbee 3.0 ไปยัง Coordinator ]
                │
                ▼
[ ได้รับ MAC ACK จาก Parent Node ]
                │
                ▼
[ เข้าสู่โหมด Deep Sleep อีกครั้ง (กินกระแสไฟ ~15 µA) ]
```

ด้วยลำดับการทำงานนี้ โหนดจะตื่นขึ้นมาทำงานเพียง **0.3 – 0.5 วินาที** ต่อ 1 รอบการวัด ทำให้แบตเตอรี่ LiFePO4 ขนาด 3200 mAh สามารถจ่ายไฟให้โพรบอุตสาหกรรมทำงานได้ต่อเนื่องนานกว่า **18 – 24 เดือน** โดยไม่ต้องชาร์จไฟ!
