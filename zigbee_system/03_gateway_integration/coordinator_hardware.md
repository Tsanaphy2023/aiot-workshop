## 1. การเปรียบเทียบชิปเซ็ตและอุปกรณ์ USB Dongle

ความเสถียรและระยะส่งสัญญาณของเครือข่าย Zigbee ในฟาร์มกว่า 80% ขึ้นอยู่กับคุณภาพของ **Zigbee Coordinator**:

| คุณสมบัติทางเทคนิค | 🏆 Sonoff ZBDongle-P (CC2652P) | Sonoff ZBDongle-E (EFR32MG21) | 🚀 Smlight SLZB-06 (PoE / LAN) |
| :--- | :--- | :--- | :--- |
| **ชิปประมวลผลหลัก** | **Texas Instruments CC2652P** | Silicon Labs EFR32MG21 | Texas Instruments CC2652P |
| **กำลังส่งสูงสุด (TX Power)** | **+20 dBm** (มี Power Amplifier) | **+20 dBm** | **+20 dBm** |
| **สายอากาศ (Antenna)** | หัวต่อ SMA ภายนอก (ถอดเปลี่ยนได้) | หัวต่อ SMA ภายนอก | หัวต่อ SMA + เสาเกนสูง |
| **พอร์ตเชื่อมต่อ (Interface)** | USB Type-A (CP2102N) | USB Type-A (CH9102F) | **Ethernet PoE / Wi-Fi / USB-C** |
| **โปรโตคอลสแต็ก** | TI Z-Stack 3.x.0 | Silicon Labs EmberZNet (EZSP) | TI Z-Stack 3.x.0 |
| **ความเสถียรบน Zigbee2MQTT** | **สูงสุด (สมบูรณ์ 100%)** | ดี (เสถียรขึ้นเรื่อยๆ) | **สูงสุด (เหมาะกับฟาร์มใหญ่)** |
| **ราคาโดยประมาณ** | ~650 – 850 บาท | ~650 – 850 บาท | ~1,200 – 1,500 บาท |

## 2. ทำไมถึงแนะนำ "Smlight SLZB-06 (PoE)" ในฟาร์มขนาดใหญ่?

ในโรงเรือนหรือแปลงปลูกจริง เซิร์ฟเวอร์หลัก (Raspberry Pi หรือ Mini PC) มักติดตั้งอยู่ในห้องควบคุม ซึ่งอาจอยู่ห่างจากโรงเรือน 50 – 100 เมตร:
* หากใช้ **USB Dongle ทั่วไป:** จะต้องเดินสาย USB ยาว ซึ่งสัญญาณดรอป และไม่สามารถนำ Coordinator ไปอยู่กลางโรงเรือนได้
* หากใช้ **SLZB-06 (PoE Ethernet):**
  * สามารถลากสายแลน (LAN Cat6) เส้นเดียวยาวได้ถึง **100 เมตร** โดยจ่ายไฟผ่านสายแลน (PoE) ได้ทันที
  * นำ Coordinator ไปติดไว้ใต้หลังคาโรงเรือนตรงกึ่งกลางแปลงปลูก ทำให้รับสัญญาณจากเซนเซอร์ทุกจุดได้แรงเต็มประสิทธิภาพ
  * Zigbee2MQTT สามารถต่อผ่าน IP Address ได้โดยตรง เช่น `tcp://192.168.1.150:8888`

## 3. กฎเหล็กป้องกันสัญญาณรบกวน (Crucial Best Practices)

> [!WARNING]
> **ข้อควรระวังสำคัญที่สุด: ปัญหาสัญญาณกวนจากพอร์ต USB 3.0**
> พอร์ต USB 3.0 (สีฟ้า) ของคอมพิวเตอร์และ Raspberry Pi จะแผ่คลื่นแม่เหล็กไฟฟ้ารบกวนที่ย่านความถี่ **2.4 – 2.5 GHz** โดยตรง หากเสียบ Zigbee Dongle เข้ากับพอร์ต USB 3.0 โดยตรง จะทำให้ระยะส่งลดลงเหลือไม่ถึง 3 เมตร และแพ็กเกตสูญหายบ่อยมาก!

### แนวทางปฏิบัติทางวิศวกรรม:
1. **ต้องใช้สายต่อพ่วง USB 2.0 Extension Cable เสมอ:** ความยาว 0.5 – 1.5 เมตร เพื่อแยกตัว Dongle ให้อยู่ห่างจากตัวเครื่องคอมพิวเตอร์หรือ Raspberry Pi
2. **เสียบเข้ากับพอร์ต USB 2.0 (พอร์ตสีดำ):** หลีกเลี่ยงการเสียบเข้าพอร์ต USB 3.0 (สีฟ้า)
3. **การวางสายอากาศ SMA:** จัดวางสายอากาศในแนวตั้งฉาก (Vertical Polarization) เพื่อให้แนวคลื่นวิทยุกระจายรอบทิศทาง 360 องศาในแนวระนาบแปลงปลูก
