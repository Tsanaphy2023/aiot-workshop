# 📖 คู่มือการติดตั้งและใช้งานระบบ Smart Farm AIoT Dashboard

ระบบ **Smart Farm AIoT Dashboard** ออกแบบมาเพื่อให้เกษตรกร นักวิจัย และผู้เรียนสามารถติดตั้งใช้งานระบบมอนิเตอร์และควบคุมฟาร์มผ่าน **เว็บเบราว์เซอร์, สมาร์ตโฟน, และบอร์ดไมโครคอนโทรลเลอร์ ESP32** ได้อย่างสะดวก รวดเร็ว และไม่ต้องพึ่งพาซอฟต์แวร์เครื่องเสมือนขนาดใหญ่

---

## 🚀 1. วิธีเปิดใช้งานหน้าแดชบอร์ดบนคอมพิวเตอร์ (แล็ปท็อป Mac / PC)

### วิธีที่ ก: เปิดผ่าน XAMPP Web Server (ทันที)
เนื่องจากโฟลเดอร์นี้อยู่ใน `htdocs` ของ XAMPP แล้ว หากเครื่องเปิด Apache ไว้อยู่ สามารถเปิดเบราว์เซอร์ไปที่:
```text
http://localhost/cmu_aiot/smart_farm_dashboard/
```

### วิธีที่ ข: เปิดไฟล์โดยตรง หรือรัน Local Web Server
1. เปิดโปรแกรม Terminal บนเครื่อง Mac
2. ไปที่โฟลเดอร์:
   ```bash
   cd /Applications/XAMPP/xamppfiles/htdocs/cmu_aiot/smart_farm_dashboard
   ```
3. รันคำสั่งเว็บเซิร์ฟเวอร์แบบเบา:
   ```bash
   python3 -m http.server 8000
   ```
4. เปิดเบราว์เซอร์ไปที่: `http://localhost:8000`

---

## 📱 2. วิธีเปิดใช้งานบนสมาร์ตโฟน (Mobile / Tablet)

1. เชื่อมต่อสมาร์ตโฟนเข้ากับ **Wi-Fi วงเดียวกันกับคอมพิวเตอร์**
2. ตรวจสอบหมายเลข IP ของคอมพิวเตอร์ (เช่น `10.100.2.179` หรือ `192.168.1.50`)
3. เปิด Safari (บน iPhone) หรือ Chrome (บน Android) แล้วพิมพ์ URL:
   ```text
   http://10.100.2.179/cmu_aiot/smart_farm_dashboard/
   ```
4. **ติดตั้งเป็นแอปบนหน้าจอมือถือ (PWA):**
   * **iOS (Safari):** กดปุ่มแชร์ (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้น) ➔ เลือก **"Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)**
   * **Android (Chrome):** แตะจุดสามจุดมุมบนขวา ➔ เลือก **"Install App" หรือ "เพิ่มลงในหน้าจอหลัก"**
   * ไอคอนแอป **SmartFarm** จะปรากฏบนหน้าจอมือถือ และเปิดใช้งานแบบเต็มหน้าจอ (Full Screen) เสมือน Mobile App ตัวจริง!

## 🤖 3. วิธีการแฟลชโปรแกรมลงบอร์ด ESP32

ในโฟลเดอร์ `firmware/` ได้เตรียมโค้ดไว้ให้ครบทั้ง 2 ภาษา:

### ทางเลือกที่ 1: ใช้ MicroPython (Thonny IDE)
1. เปิดโปรแกรม **Thonny IDE**
2. เปิดไฟล์ `firmware/esp32_micropython/config.py`:
   * แก้ไข `WIFI_SSID` และ `WIFI_PASS` ให้ตรงกับ Wi-Fi ของท่าน
   * แก้ไข `SERVER_URL` เป็น IP ของเครื่องคอมพิวเตอร์ที่เปิดแดชบอร์ด
3. บันทึกไฟล์ `config.py` และ `main.py` ลงในบอร์ด ESP32
4. บอร์ดจะเริ่มอ่านค่าเซนเซอร์ ส่งข้อมูลขึ้นแดชบอร์ด และรับคำสั่งเปิด-ปิดรีเลย์โดยอัตโนมัติ

### ทางเลือกที่ 2: ใช้ Arduino IDE (ภาษา C++)
1. เปิดโปรแกรม **Arduino IDE**
2. ติดตั้งไลบรารี:
   * `ArduinoJson` (เวอร์ชัน 6.x)
   * `DHT sensor library` โดย Adafruit
3. เปิดไฟล์ `firmware/esp32_arduino/esp32_smart_farm.ino`
4. แก้ไขชื่อ Wi-Fi, รหัสผ่าน และ `serverUrl`
5. เสียบสาย USB เข้าบอร์ด ESP32 เลือกพอร์ต และกดปุ่ม **Upload**

* ที่ด้านล่างสุดของหน้าแดชบอร์ด จะมีแผงควบคุม **Virtual Farm Simulator**
* สามารถคลิกปุ่ม:
  * **🌧️ จำลองฝนตกหนัก:** ดูว่าระบบจะตัดการรดน้ำอัตโนมัติเมื่อความชื้นสูงขึ้นหรือไม่
  * **🏜️ จำลองดินแห้งแล้ง:** ดินลดเหลือ 34% ระบบอัตโนมัติ (Smart Rule) จะสั่งเปิดวาล์วและปั๊มน้ำทันที
  * **☀️ จำลองแดดจัด:** สั่งเปิดพัดลมระบายอากาศอัตโนมัติ
* การทดสอบนี้ช่วยให้ผู้เรียนและผู้ฝึกอบรมเข้าใจกลไก AIoT ได้ครบถ้วนแม้ยังไม่มีอุปกรณ์ฮาร์ดแวร์อยู่กับตัว
