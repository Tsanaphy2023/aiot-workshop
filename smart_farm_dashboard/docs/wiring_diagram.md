# 🔌 แผนผังการต่อวงจรบอร์ด ESP32 กับเซนเซอร์และรีเลย์ควบคุมฟาร์ม
### Smart Farm AIoT System Wiring Diagram

เอกสารนี้ระบุการเชื่อมต่อสายสัญญาณระหว่างบอร์ดไมโครคอนโทรลเลอร์ **ESP32**, เซนเซอร์ตรวจวัดสภาพแวดล้อม และชุดโมดูลรีเลย์ควบคุมอุปกรณ์

---

## 📌 1. ตารางการต่อขา GPIO (Pinout Mapping)

| อุปกรณ์ / โมดูล | ขาของอุปกรณ์ | ขาบนบอร์ด ESP32 | แรงดันไฟเลี้ยง (VCC) | หน้าที่การทำงาน |
| :--- | :--- | :--- | :--- | :--- |
| **เซนเซอร์ DHT22** | VCC | 3.3V หรือ 5V | 3.3V | ไฟเลี้ยงเซนเซอร์ |
| | DATA | **GPIO 4** | — | ส่งข้อมูลอุณหภูมิและความชื้น |
| | GND | GND | 0V | กราวด์ร่วม |
| **เซนเซอร์วัดความชื้นดิน (Soil)** | VCC | 3.3V | 3.3V | ไฟเลี้ยงเซนเซอร์วัดความชื้นดิน |
| | AOUT (Analog) | **GPIO 34** (ADC1) | — | แรงดันอะนาล็อกแปรผันตามน้ำในดิน |
| | GND | GND | 0V | กราวด์ร่วม |
| **รีเลย์ CH1 (Main Valve)** | IN1 | **GPIO 18** | 5V | สั่งเปิด-ปิดโซลินอยด์วาล์วน้ำหลัก |
| **รีเลย์ CH2 (Water Pump)** | IN2 | **GPIO 19** | 5V | สั่งเปิด-ปิดปั๊มน้ำแรงดันสูง |
| **รีเลย์ CH3 (Mist System)** | IN3 | **GPIO 21** | 5V | สั่งเปิด-ปิดหัวพ่นหมอก |
| **รีเลย์ CH4 (Exhaust Fan)** | IN4 | **GPIO 22** | 5V | สั่งเปิด-ปิดพัดลมระบายอากาศ |
| **ไฟเลี้ยงโมดูลรีเลย์ (Relay Board)** | VCC | 5V (VIN / External) | 5V | จ่ายไฟขับคอยล์รีเลย์ |
| | GND | GND | 0V | กราวด์ร่วมกับ ESP32 |

## ⚠️ ข้อควรระวังในการต่อวงจรจริง
1. **เซนเซอร์ความชื้นในดิน:** แนะนำให้ใช้แบบ **Capacitive Soil Moisture Sensor (แบบสีดำ)** มากกว่าแบบขั้วโลหะเคลือบตะกั่ว เพราะไม่เป็นสนิมและไม่สึกกร่อนเมื่อใช้งานในดินระยะยาว
2. **ขาสัญญาณ Analog ของ ESP32:** ควรเลือกใช้ขาในกลุ่ม **ADC1 (เช่น GPIO 32, 33, 34, 35)** เท่านั้น ห้ามใช้ ADC2 เพราะขา ADC2 จะถูกปิดการทำงานเมื่อเปิดใช้งานชิป Wi-Fi
3. **การจ่ายไฟให้โมดูลรีเลย์:** หากขับปั๊มน้ำหรือวาล์วขนาดใหญ่ ควรแยกแหล่งจ่ายไฟ 5V สำหรับคอยล์รีเลย์ต่างหากจากบอร์ด ESP32 เพื่อป้องกันปัญหาไฟตก (Brownout Reset) ของ ESP32 เมื่อรีเลย์ทำงานพร้อมกัน
